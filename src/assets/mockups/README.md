# Mockups Folder

Upload your mockup images here. The supported formats are:
- PNG (.png)
- WebP (.webp)
- JPEG (.jpg, .jpeg)

## Files to Upload

Replace the following placeholder files with your actual mockup images:

1. **mockup-social.png** - Social media mockup (Instagram, social platforms)
2. **mockup-digital.png** - Digital content mockup (website, web apps)
3. **mockup-print.png** - Print materials mockup (business cards, printed assets)

## Recommended Specifications

- Resolution: 1200x1200px (minimum)
- Aspect Ratio: 1:1 (square)
- File Size: Under 500KB for optimal performance
- Format: PNG or WebP for best quality

Simply replace the mockup files with your own images, keeping the same filenames and the mockups will automatically appear on the brandboard.

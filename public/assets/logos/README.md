# Logo Assets

This folder contains all logo versions and variations for the Paulo Alanis brand.

## Folder Structure

- **primary/** - Main logo marks and versions
- **variations/** - Different color variations and backgrounds
- **social/** - Social media optimized versions
- **icon/** - Icon/favicon versions

## Logo Usage Guidelines

- Use SVG format for web and digital applications
- Maintain proper padding around logo (clear space)
- Avoid stretching or distorting the logo
- Refer to the brand guidelines for color usage
